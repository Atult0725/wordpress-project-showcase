# Atul Tiwari — WordPress Project Showcase

Four website projects covering custom WordPress development and visual site
building with Elementor. Each case study explains the project purpose,
technology, contribution and available previews.

| Project | Focus | Build approach |
| --- | --- | --- |
| [OurLand Property](projects/ourland-property/README.md) | Property discovery, management and enquiries | Custom WordPress, PHP and JavaScript |
| [RKSUNEX](projects/rksunex/README.md) | Digital-services brand and project portfolio | WordPress and Atomic Elementor |
| [Plant Haven](projects/plant-haven/README.md) | Plant storefront and gardening content | WordPress and Atomic Elementor |
| [Midnight Coffee](projects/midnight-coffee/README.md) | Cafe brand, drinks and visit information | WordPress, Elementor Pro and Astra |

For an interview or project discussion, open a case study to see the work and
its build approach. The Elementor projects demonstrate page composition,
styling and responsive layout configuration; OurLand Property demonstrates
custom theme, plugin and interface development.

These are project presentations with static previews. Live demo URLs will be
added after deployment and verification. Tablet and mobile images identified
as mockups represent supplied design previews.
